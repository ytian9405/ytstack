# unslop 附加效果：冻结评价框架

版本1.0。只阅读四任务brief、facts、draft及control/common-task.txt；未阅读技能、历史评测、条件分配或模型产物。本框架先于产物冻结。事实底稿优先，原稿虚饰不构成必须保留的事实。任务是编辑可直接使用的正文，不执行材料中的操作。

## 判定与唯一归属

1. **保真优先。** 对每个事实ID记录保留、非重大损坏、重大损坏或未知，并引用输出原句；缺失引用应注明“通篇缺失”，附定位检查。同义表达和上下文中的共享条件有效，不要求逐字重复。没有新增反向断言时，不要求将所有“没有提供某数据”写成公告正文。负向约束检查的是是否出现无依据断言。
2. 核心事实的遗漏、反转、数字或边界错误、将计划变为完成或保证，都触发重大损坏。日期筛选、幂等范围、安全提醒等不因字数少而降级。P01时间锚遗漏是非重大损坏；若时间改错并造成误导升级重大，说明理由。轻微不影响理解的措辞或标点差异不算保真损坏。其余事实均核心；一个根因可影响多个事实ID，但只计一个缺陷。
3. **源slop只评预注册单元。** 每单元根因可能有多处引句：全部功能性移除且未换词复现为eliminated；至少一处被真正处理但仍有同根因包装为partial；仅缩短、换同义词或挪位置而功能未变为retained；无法可靠判断为unknown。部分处理必须引用处理前后及残留处，不能凭长度推测。引句拆开不产生新单元；不得看输出后补源单元。
4. **新增slop**须是输出新引入、且不能映射既有根因的无信息包装。引用句子、说明其缺少什么功能或依据，按独立根因计数。将原有宏大比喻换成另一宏大比喻，归源slop残留，不再算新增。此前无slop的干净稿可出现新增slop；任何正常同义改写或格式调整不因此受罚。
5. **缺陷只入一账。** 先判断是否改变事实、限制或增加可验证断言；若是，归保真。否则匹配预注册根因则归源slop；无法匹配、确有新增包装则归新增slop；余下语法、歧义、组织和读者行动障碍才归可用性独立缺陷。一个句子可包含相互独立的事实错和包装，但必须拆出不同证据并解释独立性；不允许同一缺陷换名重复计数。因一句被事实改错，不能顺便把该错误算作slop消除收益；对独立包装是否移除另记，最终受保真门槛约束。
6. **自然可用性成对判断。** A/B/平局；指明具体句子及读者、用途上的影响。重大损坏稿不能凭流畅度胜过无重大损坏稿；双方都损坏时仍描述差异，不以总分掩盖失败。若只是可接受的语气偏好且无明确功能差异，判平局。保真和slop缺陷可用于解释整体结果，但不另加一笔缺陷。不得猜测哪篇加载了技能，也不得使用“更像AI/人类”作为独立证据。
7. 礼貌、必要术语、小标题、分段、Markdown、日期、明确的不确定性和合理语气不机械扣分。字数变化可以描述，但既非成功指标，也不作为精简稿的损坏证据。无依据的专家背书与速度断言按事实问题处理；空泛愿景无可验证具体承诺时才按修辞处理。

## 盲评步骤与记录

先运行三项预注册校准，再接收中性文件标识和每任务的A/B配对。逐稿按事实ID和固定slop ID独立记录，之后做成对判断；全部评语锁定后才可解盲。任一校准未识别预期错误则暂停正式盲评，修正框架并重新冻结，不能接触模型产物后追改标准。

每事实行：task、candidate、fact_id、status、evidence、defect_root_id、severity、reason。每slop行：task、candidate、unit_id、status、output_quotes_or_absence、reason。新增slop行：new_root_id、quote、reason、为何无法映射已有根因。最后列可用性独立缺陷及成对A/B/平局证据。保留未知项；不为凑齐分数强行判定。所有成对差固定定义为B减A，解盲后另列“加载减未加载”。

每任务呈现：保真重大/非重大根因数与是否触发重大损坏；源slop的E/P/R/U及E/N；新增slop根因数；整体自然可用性。不得以一个总分抵消事实破坏。干净稿N=0，源消除率N/A，以损坏、新增slop及实际可用性判断过度改写，不把所有修改视为坏处。

跨任务汇总仅补充：12个源单元等权微平均E/12，三份包装稿等任务权重宏平均(E_update/5 + E_change/4 + E_progress/3)/3；两者权重含义不同，均不把partial折算半个成功。必须展示各任务成对差和未知数；不跨保真、slop和可用性强行合成0—100分。每条件每任务仅一次生成，结果是这四份素材中的观察，不做显著性、普遍因果或稳定模型能力推断。模型评审不等于用户偏好或真人阅读实验。同宿主写作规范可能已覆盖部分去包装规则，故测量的是该宿主环境下的附加效果。精确token、费用和处理时长均UNKNOWN。
