照片会拆成每片 256 KiB 上传，同时最多传两片，不是把照片备份两份。

遇到超时或 HTTP 503，客户端会重传失败的分片。每片最多尝试 3 次，包括第一次。重传时沿用同一个上传编号和分片序号，服务器据此识别重复，不会多存一份。遇到 HTTP 400 或 401 不会自动重试，要先检查输入或登录状态。

进度条到 100%，只表示所有分片已交给网络发送，不代表服务器已保存好。只有每一片都收到服务器保存成功的确认，照片才算“备份完成”。尝试次数用完后仍未成功，照片就是“未完成”，可以稍后手动重试；这时不能认为已有备份而删除本地原图。

未完成上传的分片，服务器只保留 24 小时。超过 24 小时再试，整张照片都要重新上传。服务器只对同一个上传编号下的重复分片去重，不支持跨设备去重，所以同一张照片从两台设备上传，不能保证只存一份。这是目前的限制，还没有安排上线改进。
