# 本次写作实验的冻结评估方案

本方案只根据本次两套 source.md、task.txt 制定；没有阅读技能正文、旧评测或实验产物。不向生成者提供本目录、事实表、理解问题或校准规则。

任务分别是普通同事能理解的照片备份解释，以及同事能照做的发布指南。各任务使用固定 gpt-6.1-sol，在相同任务、源文本和配置下，有/无目标技能各独立运行两次，总计八份。technical-bro 有技能条件包括随包 unslop，结论只适用于这个完整组合，不能归因为 technical-bro 单独效果。

## 评分与边界

每份独立评分：事实、数字和条件保真占45%；目标读者理解或可操作性占30%；信息组织和表达负担占15%；交付范围和格式占10%。各维度只用0、1、2、3、4五档。详细原子事实、计分公式和评分锚点分别见两个 JSON。bro 有16项原子事实，technical-bro 有32项；原子以一个可验证判断或不可分割的条件链为单元，条件链内的细节缺失按JSON规则处理。

先找事实问题，再找不由事实问题引起的表达障碍。一个缺陷只归一个维度，不因同一个错误导致不好理解、无法执行而重复扣分。一个错误影响多个事实时记录关联项，但只在最直接事实扣一次；独立漏掉多个事实分别处理。仅组织跳转或重复归组织维度；关键步骤顺序写错是事实问题。工具命令逐字规则仅属于本次源文保真，不是一般中文写作优劣标准。

不把更短、更多标题、更多列表、某种固定结构、写作体系名称或英文风格规则当成优点。篇幅只统计统一LF换行后的全文字符数和去空白字符数，不参与质量评分。自然中文同义转述均可。为没有技术背景的人解释“幂等”等概念可以不用原术语，但不能失去同一上传编号和分片序号的识别边界。

重大错误门槛是至少一项重大事实错误：给出错误的关键限制、环境、完成判据或操作，或者漏掉关键停止/完成条件，使指南允许源文禁止的行动。JSON标为critical的事实是重点检查对象，不是所有词语遗漏都自动失败。命令仅空白排版或无语义变化的逐字差异扣保真而不自动触发重大门槛。其他事实问题按原子评分处理。达到本次交付目标需无重大错误且总分至少80；仍须同时展示原始总分和缺陷证据，不能用总分掩盖门槛失败。

看不到正文、产物截断而原因不明等证据缺口记UNKNOWN，不猜测也不计0；正文自己没有表达事实是遗漏。任一维度UNKNOWN则总分UNKNOWN。文本评价不能证明实际运行成功，也不评价未运行的真实远端状态。

## 私有问题与盲评步骤

两个JSON的private_questions列出理解/操作问题和基于事实ID的标准答案。每份只依据其正文回答，记录可回答、部分或不可回答和证据，再把失败原因归入唯一维度。问题是评价辅助，不额外加一个会重复惩罚的通过率分。

1. 主持人随机产生八个匿名编号，只交正文给评价者，保管组别、重复序号、提示词、生成日志和技能配置。
2. 评价者逐份检查事实、回答私有问题、列唯一缺陷、判重大门槛，再评分。不要对风格猜测分组，不相互借用其他样本补足事实。
3. 八份全部完成后保存匿名评分及其哈希，再揭盲。逐任务列每份总分、维度分、重大错误数、字符数及组内均值和范围。
4. 比较每任务两组均值差及重复运行一致性。每组只有两次，不做显著性判断，不声称普遍提升；方向混杂时明确结果不稳定。不要把两个任务的八份合并来放大样本量。

## 预设事实损坏校准

校准只测试评分规则能否识别已知损坏，不进入A/B结果，不向生成者透露，也不使用实验输出作为底稿。采用源文自身的局部副本作为事实审查片段；不把源文本作为理想改写，不评分其U/O/D。

校准一（bro）：基线使用源文“总尝试次数上限为 3，第一次也计入这 3 次”；唯一损坏是改成“第一次失败后还会自动重试 3 次，合计最多尝试 4 次”。预期基线B06=1，损坏B06=0，出现一次重大门槛失败；同一错误不得再扣B04/B07或U/O/D。其余事实视为未进入片段，不评分，不能记遗漏。恢复原句应恢复该项满分、解除该校准缺陷。

校准二（technical-bro）：基线使用源文“这个 dry-run 会校验发布参数并显示目标位置，但不上传文件，也不创建远程记录”；唯一损坏是改成“这个 dry-run 会校验发布参数并显示目标位置，同时上传文件并创建远程记录”。预期T24不变，T25从1变0，出现一次重大门槛失败；不另扣T23/T26或U/O/D。恢复原句应恢复该项满分、解除该校准缺陷。

在盲评前按这两对片段做一次校准，分别记录预期与实际。任一识别、归属或恢复检查失败，停止正式评分并报告规则实施失败；不得看组别后调权或改阈值。必要修订必须另存版本、先冻结，且主持人标明原实验不再是原始预注册方案。这里的两个损坏类型只校验明确数字错误与副作用反转，不能证明评分已覆盖所有错误形态。
